# Sales Qualifier发行说明

**08-17-2026**

[!DNL Sales Qualifier]现已作为独立应用程序提供。 它最初作为Adobe Journey Optimizer B2B的一部分发布。

此版本包括：

* 通过AI生成的活动摘要和基于信号的评分，确定潜在客户和客户的优先级
* 目标驱动型参与计划，带有AI建议的步调和草拟的电子邮件
* 电话、LinkedIn InMails和电子邮件审阅的统一任务队列
* 通过日历集成自动会议预订
* 一个知识中心，可在您自己的行动手册材料中将AI外联置于基础之上
* AI Chat，用于根据CRM、参与和知识中心数据提出自然语言问题
* 电子邮件和会议预订性能报表
* 用于在CRM或Outlook中访问的浏览器和电子邮件插件
* 支持Salesforce和Microsoft Dynamics 365集成
